# Семантическое ядро — барбершоп «БрутAL», Шелехов

Ключи распределены по блокам страницы. Частотность — ориентир по логике спроса малого города (Шелехов ~50 тыс. жителей + трафик из Иркутска). Перед запуском рекламы проверьте в Яндекс Вордстат.

## Высококонверсионные (коммерческие + гео)
| Запрос | Где на странице |
|---|---|
| барбершоп шелехов | title, H1, description, schema, llms.txt |
| мужская стрижка шелехов | title, hero, таблица услуг, FAQ |
| барбер шелехов | H1-блок, история, команда |
| записаться в барбершоп шелехов / запись к барберу онлайн | кнопки, FAQ, ReserveAction |
| стрижка бороды шелехов / оформление бороды | таблица (Br, Cb), прайс |
| мужская парикмахерская шелехов | meta keywords, текст |
| стрижка цена шелехов / сколько стоит мужская стрижка | прайс по мастерам, FAQ |

## Услуги (средняя частота)
- фейд / high fade / low fade, кроп, цезарь, бокс, полубокс — таблица, FAQ, alt фото
- детская стрижка шелехов, стрижка мальчику — Kd, FAQ
- камуфляж седины для мужчин, тонирование бороды — Tb, Gr, FAQ
- окантовка, окантовка бороды — Fd, Kb
- депиляция носа воском / ваксинг ушей — Wx

## Подарочные
- подарочный сертификат барбершоп, подарок мужчине шелехов, сертификат на стрижку — блок «Сертификат», FAQ

## Гео / GEO (нейропоиск: Алиса, ChatGPT, Perplexity)
- барбершоп рядом с Иркутском, барбершоп 2 квартал шелехов — schema areaServed, llms.txt
- Факты для цитирования ИИ: адрес, цены, мастера, дата открытия, 10 000+ стрижек — вынесены в llms.txt и FAQPage-разметку.
