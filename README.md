# Лендинг барбершопа «БрутAL» — Шелехов

Одностраничный сайт: HTML + отдельные CSS и JS, без сборщиков и зависимостей.

## Структура
```
index.html            — страница (11 блоков)
css/style.css         — стили, адаптив 360–1920 px
js/main.js            — бургер, табы прайса, слайдер отзывов, сертификат, лайтбокс
img/                  — оптимизированные фото (WebP + JPG-фолбэк, 2 размера)
robots.txt, sitemap.xml, llms.txt, manifest.webmanifest, favicon.svg, 404.html
seo/semantic-core.md  — семантическое ядро и план продвижения
```

## Блоки
1. Hero — «клетка» элемента 13 Al с фото, ключевые цифры
2. Таблица элементов — 10 услуг в стиле периодической системы
3. «Формула Никиты» — история владельца цепочкой-реакцией
4. Прайс по мастерам — вкладки Никита / Юлия / Елена
5. Команда
6. Цитата «Иногда счастье можно купить за деньги…»
7. Работы — галерея с лайтбоксом
8. Подарочный сертификат — живой предпросмотр, заявка в MAX / SMS
9. Отзывы — слайдер (свайп, стрелки, точки)
10. FAQ (+ разметка FAQPage)
11. Контакты + Яндекс Карта

## Перед публикацией
- **Домен**: замените `https://brutal-barber.ru` на реальный в `index.html`, `robots.txt`, `sitemap.xml`, `llms.txt`.
- **Отзывы**: в блоке `#reviews` стоят шаблоны — вставьте реальные отзывы гостей.
- **MAX**: в `js/main.js` замените `MAX_URL` на персональную ссылку владельца (`https://max.ru/u/...`). Сейчас кнопка копирует текст заявки и открывает MAX.
- **Координаты**: в `index.html` (meta geo + schema) указаны примерные — уточните по Яндекс Картам.
- Время работы не указано (нет данных) — при желании добавьте `openingHours` в schema.

## Публикация
Загрузите содержимое папки в корень хостинга (GitHub Pages, Netlify, Beget, Timeweb). Работает и при открытии `index.html` локально.
